# Mazelingo Privacy Policy

**Last updated: March 25, 2026**

## Data We Collect

Mazelingo collects and processes the following data:

- **User settings** — Translation preferences (on/off, language ratio, model selection, page lists) are stored locally in your browser using Chrome's Storage API.
- **API keys** — API keys you enter are stored locally in your browser and are never transmitted to our servers.
- **Page text** — Text content from web pages you visit is sent to third-party LLM APIs solely for the purpose of translation.

## How We Use Your Data

- Settings and API keys are used only to operate the extension and are stored locally on your device.
- Page text is sent to the LLM provider you have configured, solely for translation purposes. We do not store, log, or retain any translated text.

## Data Storage

All user data (settings, API keys, translation cache) is stored locally in your browser using the Chrome Storage API. No data is stored on our servers.

## Data Sharing

- We do **not** sell, trade, or transfer your data to any third party.
- Page text is transmitted to the LLM API provider you have selected (e.g., OpenAI, Anthropic, Google, Zhipu). This transmission is necessary to provide the translation feature. Please refer to each provider's privacy policy for how they handle data.
- No data is shared with any other third party.

## Data Retention

- All data is stored locally in your browser. Uninstalling the extension removes all stored data.
- We do not retain any data on external servers.

## Your Rights

- You can view and modify all stored settings through the extension's side panel.
- You can delete all extension data by uninstalling the extension or clearing browser data.
- You can choose which websites the extension operates on using the opt-in/opt-out page list.

## Changes to This Policy

We may update this privacy policy from time to time. Changes will be reflected in the "Last updated" date above.
